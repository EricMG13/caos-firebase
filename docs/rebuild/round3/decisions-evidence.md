AI-1 / SA-C5 — FIXED — `caos/methodology/handoff.py` now bounds a run of spaces or tabs at `MAX_WHITESPACE_RUN = 256` inside `_text`, the one door both model output and stored bytes go through before any vendor validator runs, so the vendor's quadratically backtracking heading expressions never meet a padded heading; the check is one C-level substring search over the text with tabs read as spaces (`" " * 257 in text.replace("\t", " ")`), measured at 2.4 ms over 12.8 MB of adversarial input, and the vendor file is untouched (invariant 4).
